My lyrics

Type or paste a verse as 8 lines, one line per phrase, with a blank line between verses. Start a verse with a heading like “Verse 2” if you like, and put the chorus under a line that says “Chorus”: 8 lines, or 4 if both halves of the chorus use the same words. For a second version of the chorus, add another “Chorus” block.

Saved lyrics stay in this browser on this device. Use Save to a file or Copy to keep a copy, or to move them to another device. Import a file reads that same layout back in.
